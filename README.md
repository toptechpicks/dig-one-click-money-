# 💰 DIG One-Click Money System

A simple, elegant one-click crypto faucet application that lets users claim free cryptocurrency with a single click.

![Status](https://img.shields.io/badge/status-active-brightgreen)
![License](https://img.shields.io/badge/license-MIT-blue)

## ✨ Features

- 🎯 **One-click claiming** - Users get crypto instantly with one click
- 💻 **Responsive design** - Works on desktop, tablet, and mobile
- 🔒 **Secure** - No private keys or sensitive data required
- ⚡ **Fast** - Minimal dependencies, instant load time
- 🚀 **Easily deployable** - Host on GitHub Pages, Netlify, Vercel, or any static host

## 📝 How It Works

1. User visits the website
2. User clicks the "Claim Crypto" button
3. User receives notification of their reward
4. User can check their wallet for the transferred crypto
5. User can sell or trade the crypto on exchanges like Binance, Coinbase, or Kraken

## 🚀 Getting Started

### Prerequisites
- Git
- A web browser
- (Optional) GitHub account for hosting

### Installation

1. **Clone the repository:**
   ```bash
   git clone https://github.com/toptechpicks/dig-one-click-money-.git
   cd dig-one-click-money-
   ```

2. **Open locally:**
   ```bash
   # Simply open index.html in your browser
   open index.html
   ```

### Deployment

#### Option 1: GitHub Pages (Free & Easy)
1. Go to repository settings
2. Scroll to "GitHub Pages"
3. Select `main` branch as source
4. Your site will be live at: `https://toptechpicks.github.io/dig-one-click-money-/`

#### Option 2: Netlify
1. Connect your GitHub repo to Netlify
2. Configure build settings (no build needed)
3. Deploy

#### Option 3: Vercel
1. Import from GitHub
2. Deploy with one click

## 🛠️ Customization

### Change the Wallet Address
Edit `script.js` and update:
```javascript
const WALLET_ADDRESS = "0xYourAddressHere";
```

### Modify the Reward Amount
Edit `script.js` and update:
```javascript
const REWARD_AMOUNT = "0.1 ETH"; // or "10 USDT"
```

### Customize Styling
Edit `style.css` to match your brand colors and design.
